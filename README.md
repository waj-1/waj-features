# WAJ features

WAJ runs salons, spas and clinics from one app: bookings, checkout, clients, staff, stock, marketing, reports and AI.
Each feature below has a short video (under a minute) and a page with screenshots.

Try it free at [login.waj.ai](https://login.waj.ai) · Full documentation at [waj.ai/docs](https://waj.ai/docs)
